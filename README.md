# LiquidClean for Mac

A free, open-source Mac cleaner written in Swift and SwiftUI, with a liquid glass interface. Run a Smart Scan, review what it found, and clean it up. Cleaned files go to the Trash by default, so you can get them back.

## Features

- **Smart Scan:** scans application caches, logs, crash reports, developer caches, browser data and the Trash in one go, then lets you review every item before cleaning.
- **System junk:** Mail downloads and attachments, diagnostic reports, QuickLook and font caches, Music/TV/Podcasts/App Store caches, old iOS and iPadOS firmware (IPSW), and interrupted downloads (`.download`, `.crdownload`, `.part`).
- **Developer junk:** Xcode DerivedData and iOS Device Support, Homebrew downloads, and CocoaPods, npm, pnpm, yarn, cargo, Gradle, pip and uv caches.
- **Time Machine local snapshots:** lists the APFS restore points macOS keeps on the disk, shows purgeable space, and thins or deletes them with `tmutil`.
- **App uninstaller:** removes an app from `/Applications` together with its leftovers in Application Support, Caches, Preferences, Saved Application State and WebKit.
- **Large and old files:** finds big disk images, archives, videos and documents in your home folder.
- **Memory and disk:** live RAM breakdown (active, inactive, wired, compressed, free), a **Free Up RAM** button and disk usage.
- **Safety first:** a built-in whitelist never touches `~/.ssh`, GPG keys, keychains, iCloud Drive or macOS system files. A first-launch assistant checks permissions and asks whether cleaned files go to the Trash or are deleted.

## Download and install

Requires macOS 14 or later, on Apple silicon or Intel (the app is universal).

1. Download `LiquidClean-<version>-mac.dmg` from the [latest release](https://github.com/duck28/liquidclean-for-mac/releases/latest).
2. Open the disk image and drag **LiquidClean** to **Applications**.
3. Open LiquidClean. The first time, macOS blocks it (see below).

To scan protected folders (Mail, Safari, Time Machine), give LiquidClean **Full Disk Access** in **System Settings › Privacy & Security › Full Disk Access**. The setup assistant shows you where.

### The app is not signed or notarized

Release builds are ad-hoc signed, not signed with an Apple Developer ID or notarized by Apple. When you open LiquidClean for the first time, Gatekeeper says that Apple could not verify it is free of malware and offers only **Done** or **Move to Trash**. To open it anyway:

1. Click **Done**.
2. Open **System Settings › Privacy & Security**, scroll down to the message about LiquidClean, and click **Open Anyway**. Confirm with your password.

Alternatively, remove the quarantine flag in Terminal: `xattr -dr com.apple.quarantine /Applications/LiquidClean.app`.

On macOS 14 you can also right-click the app and choose **Open**.

### Verify a download

Every release file is attested by the GitHub Actions run that built it ([build provenance](https://docs.github.com/actions/security-for-github-actions/using-artifact-attestations)). With the [GitHub CLI](https://cli.github.com):

```bash
gh attestation verify LiquidClean-1.0.0-mac.dmg --repo duck28/liquidclean-for-mac
```

## Build from source

Needs macOS 14 or later and the Xcode Command Line Tools (`xcode-select --install`); Xcode itself isn't required.

```bash
./build.sh
```

This builds a universal app (Apple silicon and Intel) at `build/LiquidClean.app` and a disk image at `build/LiquidClean.dmg`. The app is ad-hoc signed. To sign it with your own identity, pass `SIGN_IDENTITY="Developer ID Application: …" ./build.sh` (it would also need notarizing to open without a warning on other Macs).

- `./build.sh debug` builds a debug app without the disk image.
- `swift run` runs the app straight from the package.
- The [build workflow](.github/workflows/build.yml) builds every push to `main` and every pull request.

## Releasing

1. Set the new version in `Resources/Info.plist` (`CFBundleShortVersionString`, for example `1.0.1`, and increase `CFBundleVersion`).
2. Commit, then push a tag that matches the version with a `v` in front:
   ```bash
   git tag v1.0.1 && git push origin v1.0.1
   ```
3. The [release workflow](.github/workflows/release.yml) checks that the tag matches the version, builds `LiquidClean-<version>-mac.dmg` on a macOS runner, attests it, and creates a **draft** release. Review it on GitHub and publish it.
